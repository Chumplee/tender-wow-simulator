# TENDER: A World of Warcraft Life Simulator

**Play it in your browser:** https://chumplee.github.io/tender-wow-simulator/

A loving roast of a man who has never logged off. Built in Godot 4, the same engine as Tender's own game, because turnabout is fair play.

He sits. He types. The days pass outside a window he never looks out of. Your job is to torment him, gently:

- **Kill Wi-Fi** and watch the rage (he fixed it himself, obviously, it was his own router settings)
- **Yank Plug** for the full meltdown: shock, silence, then tears until you plug him back in
- **Feed Snack** to grow the can pyramid and the trash pile
- **Curtains** to make him hiss at the sunlight like a raccoon
- **Poke** him, **suggest bed** (the couch is labeled BED (UNUSED)), click the router, the power strip, the window, the man himself

Featuring an arcade start screen with hi-scores, a chiptune, a witness log that records your crimes, a scrolling fake-patch-notes ticker, and a full day/night cycle he sleeps through none of.

There is no logout button.

## Repo layout

- `/` — the exported web build (this is what GitHub Pages serves)
- `/godot-project/` — the complete Godot 4.7 project source. Open `project.godot` in Godot to remix it. Web export preset included (threads disabled, so it runs on any plain static host).

All in good fun. He knows. He started it.
